# لوحة الأداء الاستراتيجي 2026 — الجمعية الفيصلية الخيرية النسوية

لوحة تفاعلية بمقاس 16:9 لخطة «عزم 2» (2025–2030)، تقرأ بياناتها من ملف Excel «لوحة الاداء الاستراتيجية 2026».

- **الرابط المنشور:** https://hebaaloliani-hr.github.io/alfaisalya-Q1/
- تعرض اللوحة نسخة مضمّنة من ملف Excel لجميع الزوار.
- زر «ربط ملف Excel» (في Chrome أو Edge) يربط اللوحة بملف على جهاز الزائر نفسه ويحدّثها مع كل حفظ. الربط يخص جهاز الزائر فقط ولا يغيّر ما يراه الآخرون.
- لتحديث ما يراه الجميع: تُستبدل `index.html` بنسخة جديدة مبنية من ملف Excel المحدّث.
